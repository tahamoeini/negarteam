# Negar brand assets

Approved Negar logo exports are stored in `src/assets/`:

- `Negar-Team-Logo.png` is the mark used for the favicon.
- `Negar-Team-Logotype.png` is the standalone logotype used in the header.
- `Negar-Team-Primary-Lockup.png` is used in the closing section.

The logo PNGs have transparent outer pixels. Keep the supplied artwork unaltered and preserve its proportions. The light theme places it on the warm paper surface; the dark theme keeps the same warm paper surface behind the dark-blue marks for contrast. `public/favicon.png` is a copy of the supplied mark for browser tabs.

The page colors and typography are defined in `src/styles.css`. The design guide does not specify verified CSS color values or font files, so the repository stylesheet remains the implementation source for those choices.
