# Negar brand assets

Approved Negar logo exports are stored in `src/assets/`:

- `Negar-Team-Logo.png` is the mark used in the hero and favicon.
- `Negar-Team-Logotype.png` is the standalone wordmark export.
- `Negar-Team-Primary-Lockup.png` is the full lockup used in the header and closing section.

The logo PNGs have transparent outer pixels. Preserve the supplied geometry and proportions. The light theme displays the original dark-blue artwork on the warm paper surface; the dark theme applies the existing CSS light tint so the mark stays legible without a backing panel. `public/favicon.png` is a copy of the supplied mark for browser tabs.

The page colors and typography are defined in `src/styles.css`. The design guide does not specify verified CSS color values or font files, so the repository stylesheet remains the implementation source for those choices.
