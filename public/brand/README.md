# Negar brand assets

This folder is reserved for the approved Negar Team primary lockup and icon. They were not present in the repository when this site was built, so the site uses a plain text wordmark and does not redraw the mark.

Add the approved SVG files here when available, then update the header and closing wordmark in `src/App.tsx`. Replace the temporary initial favicon in `public/favicon.svg` with an approved favicon export if one exists.

The current site colors are design tokens in `src/styles.css`; confirm them against the approved brand palette before treating them as canonical.
